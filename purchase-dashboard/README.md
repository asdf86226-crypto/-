# 구매요청 대시보드

개발 · 자재 · 생산 · 품질 팀의 구매요청을 한 곳에서 접수하고 정리하는 단일 파일 대시보드입니다.
별도 설치나 서버 없이 `index.html` 을 브라우저로 열면 바로 동작합니다.

## 실행

```bash
# 파일을 더블클릭하거나, 로컬 서버로 열기
python -m http.server -d purchase-dashboard 8080
# → http://localhost:8080
```

## 두 가지 사용 모드

| | 로컬 모드(기본) | 구글 시트 공유 모드 |
|---|---|---|
| 입력 | 대시보드에서 직접 입력 / 엑셀 붙여넣기 | 구글 폼으로 제출 |
| 저장 | 내 브라우저(localStorage) | 구글 시트(팀 전체 공유) |
| 용도 | 혼자 정리 · 시험 사용 | 여러 팀이 함께 사용 |

## 주요 기능

- **직접 입력**: 요청팀, 품목코드, 품명, 수량, 입고요청일, 기타사항(+요청자)을 폼으로 입력
- **엑셀 붙여넣기**: 엑셀에서 표를 복사해 붙여넣으면 자동으로 여러 건을 일괄 등록
  - 인식 열 순서: `품목코드 · 품명 · 수량 · 입고요청일 · 기타사항`
  - 맨 윗줄 헤더는 자동 감지하여 제외, 요청팀은 붙여넣기 화면에서 선택
- **구글 폼 + 시트 공유**: 팀원은 구글 폼으로 제출, 대시보드는 응답 시트를 자동으로 읽어 표시(약 20초 주기)
- **팀별 필터 · 검색 · 정렬**: 상단 탭으로 팀 필터, 열 머리글 클릭 정렬, 품목코드/품명 검색
- **상태 관리**: (로컬) 접수 → 진행 → 완료 순환, 입고요청일 기한 초과/임박 자동 표시
- **요약 집계**: 총 요청 · 진행 중 · 지연 · 완료 건수 상단 표시
- **CSV 내보내기**: 현재 목록을 CSV(UTF-8)로 저장
- **라이트/다크 테마** 지원

## 팀 공유 설정 (구글 폼 + 시트)

우측 상단 **`로컬 저장`** 버튼(또는 상단 배너의 `구글 폼·시트 연결`)을 눌러 설정합니다.
**API 키나 SQL 없이 링크 2개만** 붙여넣으면 됩니다.

**1. 구글 폼 만들기** — [forms.new](https://forms.new) 에서 새 폼 생성 후 질문 추가:
   - 요청팀(객관식: 개발·자재·생산·품질), 품목코드, 품명, 수량, 입고요청일(날짜), 기타사항, 요청자

**2. 응답을 시트로 연결 + 웹에 게시**
   - 폼 상단 **응답** 탭 → **스프레드시트에 연결**(초록 아이콘)
   - 열린 시트에서 **파일 → 공유 → 웹에 게시** → 형식 **쉼표로 구분된 값(.csv)** → **게시** → 링크 복사

**3. 폼 링크 복사** — 폼 우측 상단 **보내기 → 링크(🔗)** → URL 복사

**4. 대시보드 설정 모달**에 ① 게시된 CSV 링크, ② 폼 링크를 붙여넣고 **연결 테스트 → 저장하고 연결**
   - 폼 질문 제목으로 열을 자동 인식하므로 열 순서는 달라도 됩니다.
   - (선택) 시트 편집 링크를 넣으면 대시보드에서 바로 시트를 열어 상태를 수정할 수 있습니다.

연결 정보(링크)는 각 사용자 브라우저에만 저장되며 HTML 안에는 들어가지 않습니다.
따라서 `index.html` 을 공용 주소(GitHub Pages/Netlify 등)에 올린 뒤, 팀원 각자가 한 번씩 위 설정을 하면
같은 시트를 함께 보게 됩니다.

### 상태(접수·진행·완료) 관리

공유 모드에서 대시보드는 시트를 **읽기 전용**으로 표시합니다. 상태를 관리하려면 시트에
**`상태`** 열을 추가하고 값을 `접수`/`진행`/`완료` 로 입력하세요(드롭다운 권장). 대시보드가 자동으로 반영합니다.

## 데이터 저장 위치

- **로컬 모드(기본)**: 브라우저 localStorage(키 `purchase_requests_v1`) — 내 브라우저에만 저장
- **공유 모드**: 구글 시트 — 팀원 전체 공유(대시보드는 읽기, 입력은 구글 폼)

> ⚠️ '웹에 게시'된 시트는 링크를 아는 사람이 내용을 **볼 수 있습니다**. 민감 정보는 넣지 마세요.
> 폼과 시트를 사내 구글 계정(조직 전용)으로 관리하면 외부 노출을 줄일 수 있습니다.
