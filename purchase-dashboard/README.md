# 구매요청 대시보드

개발 · 자재 · 생산 · 품질 팀의 구매요청을 한 곳에서 접수하고 정리하는 단일 파일 대시보드입니다.
별도 설치나 서버 없이 `index.html` 을 브라우저로 열면 바로 동작합니다.

## 실행

```bash
# 파일을 더블클릭하거나, 로컬 서버로 열기
python -m http.server -d purchase-dashboard 8080
# → http://localhost:8080
```

## 두 가지 모드

| | 로컬 모드(기본) | 구글 시트 공유 모드 |
|---|---|---|
| 저장 | 내 브라우저(localStorage) | 구글 시트(팀 전체 공유) |
| 입력 | 대시보드에서 직접 입력 | **대시보드에서 직접 입력**(동일) |
| 보기 | 나만 | 팀원 모두 실시간 |
| 설정 | 없음 | 대표자 1명이 1회만 |

> 핵심: **팀원은 대시보드에서 평소처럼 입력**하기만 하면 되고, 그 내용이 자동으로 공용 구글 시트에 저장되어
> 모두에게 보입니다. 팀원은 별도 설정이 전혀 없습니다.

## 주요 기능

- **직접 입력**: 요청팀, 품목코드, 품명, 수량, 입고요청일, 기타사항(+요청자)
- **엑셀 붙여넣기**: 엑셀 표를 복사해 붙여넣으면 여러 건 일괄 등록
- **실시간 공유**: 구글 시트 연결 시 약 10초 주기로 자동 동기화(팀원 입력이 내 화면에 나타남)
- **상태 관리**: 접수 → 진행 → 완료 순환, 입고요청일 기한 초과/임박 자동 표시
- **팀별 필터 · 검색 · 정렬**, **요약 집계**, **CSV 내보내기**, **라이트/다크 테마**

## 팀 공유 설정 (구글 시트 + Apps Script) — 대표자 1명, 1회만

우측 상단 **`로컬 저장`** 버튼(또는 배너의 `구글 시트 연결`)을 눌러 설정합니다.
**API 키·SQL 없이** 코드를 붙여넣고 배포 URL 하나만 가져오면 됩니다.

**1. 시트 만들고 스크립트 열기**
   - [sheets.new](https://sheets.new) 로 빈 스프레드시트 생성
   - 메뉴 **확장 프로그램 → Apps Script**
   - 기존 코드 지우고, 대시보드 모달에 있는 코드를 붙여넣고 **저장**

**2. 웹앱으로 배포**
   - **배포 → 새 배포** → 유형 **웹 앱**
   - **실행: 나 / 액세스 권한: 모든 사용자** → **배포**
   - 권한 요청 시 본인 계정 승인(**고급 → 이동**)
   - 표시된 **웹 앱 URL**(`…/exec`) 복사

**3. 대시보드에 붙여넣기** → **연결 테스트 → 저장하고 연결**

**4. 팀원 공유** — 설정 창의 **`🔗 팀원 공유용 링크 복사`** 로 링크를 만들어 팀원에게 전달
   - 팀원은 그 링크만 열면 자동 연결됨(설정 불필요)
   - 단, 팀원이 열려면 `index.html` 이 **공용 주소**(GitHub Pages/Netlify 등)에 올라가 있어야 합니다.

### 동작 방식(CORS 우회)

- 읽기: JSONP(`<script>`)로 웹앱 `doGet` 호출 → 목록 수신
- 쓰기: `fetch(..., mode:'no-cors')` 로 `doPost` 에 add/update/remove/clear 전송 후 재조회
- 데이터는 시트의 `requests` 탭에 `id, createdAt, team, code, itemName, qty, dueDate, status, requester, note` 열로 저장

## 데이터 저장 위치

- **로컬 모드(기본)**: 브라우저 localStorage(키 `purchase_requests_v1`)
- **공유 모드**: 연결된 구글 시트(대표자 계정 소유)

> ⚠️ 웹앱을 '모든 사용자' 액세스로 배포하면 **URL을 아는 사람은 누구나** 읽고 쓸 수 있습니다.
> 공유 링크를 사내에서만 배포하세요. 더 엄격히 하려면 배포 액세스를 '조직 내 사용자'로 제한할 수 있습니다.
