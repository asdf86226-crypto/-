구글 폼 + 시트 연결

팀원은 구글 폼으로 제출하고, 이 대시보드는 응답이 모인 구글 시트를 자동으로 읽어와 보여줍니다. 키·코드 없이 링크만 붙여넣으면 됩니다.

1구글 폼 만들기
  1. forms.new 에서 새 폼 생성
  2. 질문 추가: 요청팀(객관식: 개발·자재·생산·품질), 품목코드, 품명, 수량, 입고요청일(날짜), 기타사항, 요청자
2응답 → 시트 연결 후 '웹에 게시'
  1. 폼 상단 응답 탭 → 스프레드시트에 연결(초록 아이콘)
  2. 열린 시트에서 파일 → 공유 → 웹에 게시
  3. 형식을 쉼표로 구분된 값(.csv) 로 → 게시 → 나온 링크 복사
3폼 링크 복사
  1. 폼 우측 상단 보내기 → 링크(🔗) 아이콘 → URL 복사
