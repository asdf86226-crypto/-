  • 이윤 30%의 정의. 원가 가산은 입고원가 × 1.30, 판매가 마진은 입고원가 ÷ 0.70 입니다. 입고원가 10,000원이면 각각 13,000원 / 14,286원으로, 실제 마진율은 30% vs 23.1%로 갈립니다. 사내에서 쓰는 쪽으로 고정해 주세요.
  • 부대비용 8%의 산정 기준. 지금은 물품대(원화 환산액)에 일괄 8%를 곱합니다. 관세는 HS코드별로, 운임은 중량·부피 기준이라 품목별 편차가 크면 통관비·운임을 실비로 분리하는 편이 정확합니다.
  • 환율 적용 시점. 기본값은 전월 평균환율입니다 — 9월에 열면 8월 평균이 자동으로 잡힙니다. 매입일 환율 / 통관 과세환율 / 결제일 환율로 대사해야 한다면 기준을 직접 입력으로 바꿔 쓰세요.
  • 월평균 환율은 자동으로 받아오지 않습니다. 브라우저 보안 정책상 외부 사이트를 직접 읽을 수 없어, 매달 한 번 서울외국환중개 표를 붙여넣는 방식입니다. 저장된 값은 이 PC 브라우저에 남습니다.
