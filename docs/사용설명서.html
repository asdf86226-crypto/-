구매요청 대시보드

구매요청, 이렇게 올려주세요

개발·자재·생산·품질 팀의 구매요청을 한 곳에 모으는 화면입니다. 링크만 열면 바로 쓸 수 있고, 따로 설치하거나 가입할 것은 없습니다.

1

시작하기

처음 한 번만 확인

전달받은 링크를 열면 바로 사용할 수 있습니다. 즐겨찾기에 추가해 두면 편합니다.

✓ 화면 오른쪽 위를 먼저 확인하세요.
구글 시트 연결 초록색이면 정상입니다. 입력한 내용이 팀 전체에 공유됩니다.
! 로컬 저장 회색으로 보인다면 멈춰주세요.
공유가 안 되는 상태라, 입력해도 담당자에게 전달되지 않습니다. 받으신 링크 대신 주소만 입력해 들어온 경우일 수 있으니, 전달받은 링크로 다시 접속하거나 담당자에게 알려주세요.

3

여러 건 올리기 — 엑셀 파일

한 번에 수십 건

이미 엑셀로 정리해 두셨다면 엑셀 파일 탭에서 파일을 올리시면 됩니다. 붙여넣기가 아니라 파일을 그대로 선택하거나 끌어다 놓으면 자동으로 읽어옵니다.

순서

올리는 방법

.xlsx 또는 CSV 파일

  1. 요청팀을 먼저 선택합니다
  2. 상자를 눌러 파일을 선택하거나, 상자 위로 끌어다 놓습니다
  3. “3건 인식”처럼 건수가 뜨는지 확인합니다
  4. 인식된 항목 일괄 추가를 누릅니다
준비

파일 만들기

양식이 없다면

  1. 양식(CSV) 내려받기를 누릅니다
  2. 엑셀로 열어 아래 줄에 품목을 채웁니다
  3. 저장한 뒤 위 순서대로 올립니다

열 순서는 아래와 같아야 합니다. 맨 윗줄 제목은 자동으로 걸러내니 그대로 두셔도 됩니다.

올린 뒤 확인하기

오른쪽 목록에 모든 팀의 요청이 함께 표시됩니다. 다른 사람이 올린 내용도 10초 안팎이면 자동으로 나타납니다.

내 팀 것만 보기

목록 위쪽의 팀 이름(개발·자재·생산·품질)을 누르면 그 팀 요청만 걸러서 봅니다. 전체를 누르면 다시 모두 보입니다.

찾기와 정렬

오른쪽 위 검색창에 품목코드나 품명을 넣으면 바로 찾습니다. 표의 제목(접수일·수량·입고요청일 등)을 누르면 그 기준으로 정렬됩니다.

엑셀로 내려받기

목록 아래 ⬇ CSV 내보내기를 누르면 지금 보이는 목록을 엑셀에서 열 수 있는 파일로 받습니다.

주의사항

꼭 읽어주세요
⚠ 삭제는 모두에게 적용됩니다. 각 줄 끝의 ✕를 누르면 그 요청이 모든 사람의 화면에서 사라집니다. 내가 올린 것이 아니라면 지우지 마시고, 잘못 올렸을 때만 본인 것을 지워주세요. 아래쪽 전체 삭제는 되돌릴 수 없으니 누르지 마세요.
! 수정 기능은 아직 없습니다. 잘못 올렸다면 그 줄을 지우고 다시 올려주세요.
i 요청이 접수되면 구매 담당자에게 알림이 갑니다. 올리신 뒤 따로 연락하지 않으셔도 됩니다. 급한 건은 기타사항에 “긴급”이라고 적어주세요.
6

자주 묻는 질문

휴대폰으로도 되나요?
됩니다. 링크를 열면 화면 크기에 맞춰 표시됩니다. 다만 엑셀 파일 올리기는 PC가 편합니다.
품목코드를 모르면 어떻게 하나요?
품명을 최대한 자세히 적고, 기타사항에 규격·용도·사용처를 남겨주세요. 품목코드 칸에는 미상이라고 적어두시면 담당자가 확인 후 채웁니다.
같은 품목을 또 올렸어요.
중복된 줄 하나를 ✕로 지워주세요. 그대로 두면 담당자가 두 건으로 볼 수 있습니다.
올렸는데 목록에 안 보여요.
잠시 뒤 자동으로 나타납니다. 그래도 안 보이면 오른쪽 위 새로고침(⟳)을 눌러보세요. 그래도 없다면 연결 표시가 초록색인지 확인하고, 회색이면 담당자에게 알려주세요.
수량을 아직 확정 못 했어요.
예상 수량을 적고 기타사항에 “수량 확정 전”이라고 남겨주세요. 확정되면 지우고 다시 올리시면 됩니다.
화면이 눈부셔요 / 어둡게 보고 싶어요.
오른쪽 위 ◑ 버튼을 누르면 밝은 화면과 어두운 화면이 바뀝니다.
